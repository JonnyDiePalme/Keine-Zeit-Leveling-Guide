# Keine Zeit Leveling Guide

**No time to waste.** An all-in-one leveling companion for WoW Forever: an optimized quest route, built-in navigation, dungeons and exploration in one clean addon.

## Features
- **Calculated quest route** instead of a static guide, with three pace settings (All, Normal, Fast)
- **Navigation** with waypoint arrow, mini window and route on the map, built on a precomputed path network
- **Dungeons, raids and tours** as part of the route
- **Group play**: sync your route with your group, German and English players each see their own language
- **After level 60**: catch up on all open quests
- **Optional add-on** `Keine Zeit Leveling Guide: Farming` for professions and gold farming

## Requirements
- WoW Forever (Classic Era client)
- [Questie](https://www.curseforge.com/wow/addons/questie) (required)

## Installation
1. Download the latest release
2. Unzip into `World of Warcraft\_classic_era_\Interface\AddOns\`
3. Make sure the folder is named `KeineZeitLevelingGuide`
4. Optional: also install `KeineZeitLevelingGuide_Farming`

## Usage
Type `/klg` in game, or open your character frame (**C**) and use the Keine Zeit tab.

## Bug Reports
The addon is in beta. Please report bugs with your log on our [Discord](https://discord.gg/nhTDVfBjTF). How to create a log is explained in the addon under **Help**.
